# ✅ بک‌لاگ ایجنت Frontend — IndustrialPlatform

> منبع فازبندی: `docs/07-Roadmap.md`. هر بخش وابسته به آماده‌شدن اندپوینت متناظر در `docs/backend/Tasks.md` است — قبل از پیاده‌سازی، وجود مستندسازی آن در `docs/04-Api-Contract.md` را چک کنید.

## فاز ۰ — فونداسیون
- [ ] اسکلت پروژه React + Vite + TypeScript + Redux Toolkit در `web/`
- [ ] پیکربندی RTL کامل و فونت فارسی
- [ ] لایه‌ی `api/baseApi` (RTK Query) با Interceptor برای پاکت `ApiResponse<T>` و رفرش خودکار توکن
- [ ] صفحه‌ی عمومی Health/Placeholder برای تایید اتصال به Api

## فاز ۱ — احراز هویت
- [ ] صفحه ورود: دریافت شماره موبایل → درخواست OTP → ورود کد → دریافت و ذخیره توکن
- [ ] مدیریت نقش‌محور مسیرها (Route Guard برای Admin/CompanyManager/Candidate)
- [ ] هندل خطای `OTP_INVALID_OR_EXPIRED` و `RATE_LIMIT_EXCEEDED` با پیام فارسی مناسب

## فاز ۲ — پروفایل شرکت
- [ ] فرم ثبت/ویرایش شرکت (نام، شناسه ملی، شماره ثبت، انتخاب شهرک صنعتی از لیست، آدرس دقیق)
- [ ] آپلود لوگو و گالری تصاویر
- [ ] نمایش وضعیت Verification با برچسب رنگی
- [ ] پنل ادمین: لیست شرکت‌های در انتظار تایید + اکشن تایید/رد

## فاز ۳ — آگهی‌های استخدام
- [ ] صفحه عمومی لیست/جست‌وجوی آگهی با فیلترهای صنعتی (شهرک، زون، شیفت، سرویس، وعده غذایی، بیمه)
- [ ] صفحه جزئیات آگهی
- [ ] پنل شرکت: فرم ایجاد/ویرایش آگهی، مدیریت چرخه وضعیت (انتشار/بستن)

## فاز ۴ — کارجو و درخواست‌ها
- [ ] فرم پروفایل/رزومه کارجو (سوابق، مهارت‌های دستگاهی، وضعیت نظام‌وظیفه)
- [ ] دکمه/فرم «ارسال درخواست» روی صفحه جزئیات آگهی
- [ ] صفحه پیگیری وضعیت با کد رهگیری (بدون نیاز به ورود)
- [ ] پنل شرکت: لیست درخواست‌های دریافتی هر آگهی + تغییر وضعیت (Reviewed/InterviewScheduled/Accepted/Rejected)

## فاز ۵ — پرداخت و آماده‌سازی انتشار
- [ ] صفحه انتخاب پلن ارتقاء/نردبان آگهی + اتصال به درگاه ZarinPal (Redirect + بازگشت نتیجه)
- [ ] بازبینی کامل پیام‌های خطا مطابق رجیستری سند ۰۴
- [ ] تست دستی Responsive (موبایل/دسکتاپ) برای تمام صفحات اصلی
- [ ] بررسی Accessibility پایه (کنتراست رنگ، لیبل فرم‌ها)
