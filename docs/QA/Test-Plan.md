# 🧪 طرح تست — IndustrialPlatform

> این طرح تست همگام با فازبندی `docs/07-Roadmap.md` به‌روزرسانی می‌شود. هر سناریو به سند مرجع ارجاع دارد.

## ۱. احراز هویت (Auth / OTP) — مرجع: سند ۰۵
| # | سناریو | نتیجه مورد انتظار |
| :--- | :--- | :--- |
| A-01 | درخواست OTP با شماره موبایل معتبر | کد ارسال، `expiresInSeconds: 120` |
| A-02 | درخواست OTP بیش از ۳ بار در ۱۰ دقیقه | خطای `RATE_LIMIT_EXCEEDED` (429) |
| A-03 | تایید OTP با کد صحیح در بازه زمانی معتبر | صدور Access/Refresh Token + اطلاعات کاربر |
| A-04 | تایید OTP با کد نادرست یا منقضی | خطای `OTP_INVALID_OR_EXPIRED` (400) |
| A-05 | ۵ تلاش ناموفق پیاپی تایید OTP | قفل شماره موبایل به مدت ۱۵ دقیقه |
| A-06 | استفاده از Access Token منقضی روی اندپوینت محافظت‌شده | خطای `UNAUTHORIZED` (401) |
| A-07 | چرخش Refresh Token (استفاده مجدد از توکن قبلی پس از رفرش) | رد درخواست (Token Reuse Detection) |

## ۲. پروفایل شرکت (Company) — مرجع: سند ۰۲، ۰۳
| # | سناریو | نتیجه مورد انتظار |
| :--- | :--- | :--- |
| C-01 | ثبت شرکت با شناسه ملی معتبر و یکتا | ایجاد با وضعیت `PendingVerification` |
| C-02 | ثبت شرکت با شناسه ملی تکراری (روی رکورد فعال) | خطای `DUPLICATE_NATIONAL_ID` (409) |
| C-03 | ثبت شرکت با شناسه ملی متعلق به یک رکورد **حذف‌شده منطقی** | مجاز بودن ثبت مجدد (تست مستقیم قانون Soft Delete + Partial Unique Index) |
| C-04 | تایید شرکت توسط نقش Admin | تغییر وضعیت به `Verified` |
| C-05 | تلاش تایید شرکت توسط نقش CompanyManager | خطای `FORBIDDEN` (403) |
| C-06 | ویرایش پروفایل شرکت توسط CompanyManager متعلق به شرکت دیگر | خطای `FORBIDDEN` (403) — تست Ownership Check |

## ۳. آگهی‌های استخدام (JobAd) — مرجع: سند ۰۲، ۰۴
| # | سناریو | نتیجه مورد انتظار |
| :--- | :--- | :--- |
| J-01 | ایجاد آگهی در وضعیت `Draft` | ذخیره موفق، عدم نمایش در لیست عمومی |
| J-02 | انتشار آگهی معتبر | تغییر به `Published`، ظاهر شدن در جست‌وجوی عمومی |
| J-03 | انتشار آگهی ناقص (بدون فیلد اجباری) | خطای `VALIDATION_ERROR` (400) |
| J-04 | جست‌وجوی آگهی با فیلتر `industrialZoneId` + `workShift` | فقط آگهی‌های منطبق در `data.items` |
| J-05 | عبور تاریخ انقضای آگهی منتشرشده | تغییر خودکار وضعیت به `Expired` (تست Background Job) |
| J-06 | بستن آگهی توسط شرکت غیرمالک | خطای `FORBIDDEN` (403) |
| J-07 | صفحه‌بندی لیست آگهی (`page`, `pageSize`) | `totalCount`, `totalPages` صحیح |

## ۴. کارجو و درخواست همکاری — مرجع: سند ۰۲، ۰۵
| # | سناریو | نتیجه مورد انتظار |
| :--- | :--- | :--- |
| R-01 | ثبت رزومه با اطلاعات معتبر | ایجاد موفق |
| R-02 | ارسال درخواست برای آگهی `Published` | ایجاد `JobApplication` با وضعیت `Submitted` + صدور `TrackingToken` |
| R-03 | ارسال درخواست برای آگهی `Closed`/`Expired` | خطای `JOB_AD_NOT_PUBLISHABLE` (409) |
| R-04 | پیگیری وضعیت با `TrackingToken` معتبر (بدون ورود) | نمایش وضعیت فعلی درخواست |
| R-05 | تغییر وضعیت درخواست توسط شرکت (`Reviewed`→`InterviewScheduled`→`Accepted`/`Rejected`) | ثبت صحیح توالی مجاز؛ رد توالی نامعتبر (مثلاً `Accepted`→`Submitted`) |
| R-06 | بررسی پاسخ عمومی آگهی/شرکت | عدم وجود شماره موبایل کامل کارجو/کارفرما در خروجی (Privacy Proxy) |
